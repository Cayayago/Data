# COMANDOS EN GIT / GIT BASH
Si me muestra la ruta de la siguiente manera, quiere decir que me encuentro en el directorio raiz o principal (Disco duro)

`CARLOS@DESKTOP-E2F20PK MINGW64 ~`

### cd 
nos permite cambiar de directorio, usualmente nos lleva al directorio raiz.
### cd "namedirectory"
Anteponemos cd y luego el nombre de la carpeta de la que queremos, en el caso de que el nombre de la carpeta o directorio tenga espacios los escribimos en comillas dobles (" ").
### cd ..
Me devuelve a la carpeta inmediatamente anterior.
### ls
A traves de este comando, lista los documentos que tengo en la carpeta.
### ls -a
Me lista los documementos, pero la particularidad es me muestra los que estan ocultos.
### mkdir
A traves de este comando creamos una carpeta en la ubicación donde nos encontremos.
### rmdir 
A traves de este comando puedio eliminar un documento en la carpeta donde me encuentro.
### pwd 
Me muestra la ruta completa donde me encuentro.
### clear 
Al digitar este comando, me limpia el cuadro de mando y me deja en la ubicación donde estoy trabajando.
### code .
Cuando esto en git bash, digito este comando y me abre Visual Studio Code.
## Configuración Area de trabajo del Desarrollador.
### rm -rf .git
Funciona para eliminar la rama ya creada. 
### git add .
Agrega todos los documentos a la area e Station. 
### git add
Agrega a la arae de station solo los documentos que les mencionamos. 
### git status
Me muestra en que estado se encuentra el archivo. si esta de color verde, me dice que esta en el arae de statió,pero si esta en rojo esta en directory. 
### git commit -m 
A traves de este comando se menciona que se realizo"breve"
### git remoite add origin
Al agregar el enlace de git hub a este comando nos sube el archivo al repositorio remoto
### git remote -v
Nos muestra a que repositorio esta conectado.
### git push origin u-
u- Se refiere al usuario.
